Política de privacidad

rclone-drive es una aplicación de uso estrictamente personal.

  • Accede a Google Drive solo con la autorización del propietario de la cuenta, para sincronizar sus propios archivos con su computadora.
  • Los datos de Google Drive y los tokens de acceso se guardan únicamente en la computadora del propietario.
  • No se recopilan, venden ni comparten datos con terceros, y no se usan para publicidad.
  • El acceso se puede revocar en cualquier momento desde myaccount.google.com/connections.

El uso de los datos recibidos de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
